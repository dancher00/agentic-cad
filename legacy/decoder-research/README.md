# Frozen pre-v0.2 research archive

This directory preserves the repository's earlier generative CAD-decoder,
T-LESS, DeepCAD, and Fusion 360 experiments for provenance. It includes the
Cadrille adapter experiments, benchmark ledgers, scripts, documents, and tests
that existed before the v0.2 product reset.

The archive is intentionally unsupported and excluded from packaging, Ruff,
mypy, pytest, CI, README claims, and current release results. Relative imports
and old commands may no longer work after the active package was simplified.
Nothing in this directory is an implicit dependency of the RGB-to-B-Rep product.

The exact pre-reset state is recoverable from branch
`archive/pre-v0.2-decoder-research-20260812` at commit
`b246582fa4c94daf6e8e78b02acf4bb6131355f6`.

Do not cite archived metrics as v0.2 product performance. They remain only to
make the change in direction auditable and to avoid deleting prior work.
