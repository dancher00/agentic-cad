# Ray-section demo observations

Apache-2.0, project-generated data. A rotated L-bracket, 16 calibrated views,
128 x 128 masks and simulated first-hit camera-z depth. Gaussian depth noise has
standard deviation 0.001 times object maximum extent; 10% of depths are missing.

Generated by `scripts/run_ray_section_study.py generate --instances 3 --seed 42`,
case `002-l_bracket`. This is a development example, not a held-out result and
not photographs. No reference mesh is bundled in this inference example.

Run from repository root:

```bash
da3-cad ray-sections sample_data/ray_sections/observations.npz \
  --output outputs/ray-demo --device auto
```
