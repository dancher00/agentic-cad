# Public benchmark v2 fixtures

This directory contains the redistributable DA3-CAD release benchmark:
**10 objects × 12 views = 120 RGB images**, matching target masks, calibrated
pinhole cameras and evaluator-only reference STEP/STL solids.

All files here are generated by this project and distributed under Apache-2.0.
No third-party photographs, model outputs or checkpoint data are included.

```text
public_benchmark_v2/
├── manifest.json
└── <case>/
    ├── views/view_*.png       reconstruction input
    ├── masks/view_*.png       selected-target input
    ├── cameras.npz            fixed K/E and millimetre scale
    ├── gt.step                evaluator only
    ├── gt.stl                 evaluator only
    └── manifest.json
```

The batch runner passes only `views/`, `masks/` and `cameras.npz` to
reconstruction. Reference CAD is opened later by a separate evaluator process.

Regenerate and run all cases from the repository root:

```bash
python scripts/build_public_benchmark_cases.py
python scripts/run_public_benchmark.py
```

See [benchmark setup and results](../../docs/BENCHMARKS.md).
